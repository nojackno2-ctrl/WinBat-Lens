# ⚡ WinBat Lens v1.0.0 - Official Release

Welcome to the official release of **WinBat Lens v1.0.0**!  
A modern, dark-themed Windows Battery Diagnostics & Real-Time Full-System Hardware Power Monitoring Dashboard.

---

### ✨ Key Highlights

- 🔋 **Battery Health Score & Degradation**: Health Score %, Design vs Full Capacity, Loss mWh, Cycles, and Capacity Degradation History table.
- ⚡ **Full System Hardware Power Breakdown**: Real-time wattage and load breakdown across CPU, Discrete GPU (dGPU), Integrated GPU (iGPU), Screen Backlight, Wi-Fi, SSD/HDD Disk, RAM, and Motherboard.
- 📈 **60-Second Task Manager Style Live Waveform Chart**: Live charging (+W) and discharging (-W) polylines with 5-tier Y-axis dynamic wattage scale.
- 🔌 **Total AC Adapter Supplied Wattage**: Real-time AC input wattage from wall socket vs battery charge rate vs system hardware draw.
- 🟢🔴 **Dynamic Taskbar System Tray Icon**: Real-time wattage digits rendered directly on Windows Taskbar in Emerald Green (Charging) or Crimson Red (Discharging).
- 🌐 **1-Click Dual-Language**: Instant toggle between Traditional Chinese (繁體中文) and English.
- 🚀 **100% Standalone Portable**: Self-contained executable (`WinBatLens.exe`), zero dependencies required!
