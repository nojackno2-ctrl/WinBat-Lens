# ⚡ WinBat Lens v1.0.0 - Official Standalone Release

Welcome to the official release of **WinBat Lens v1.0.0**!  
A modern, dark-themed Windows Battery Diagnostics & Real-Time Full-System Hardware Power Monitoring Dashboard.

---

### ✨ Key Features & Highlights

- 🔋 **Battery Health Diagnostics**: Health Score %, Design vs Full Capacity, Capacity Loss (mWh), Charge/Discharge cycles, and Degradation History table.
- ⚡ **Full-System Real-Time Power Breakdown**: Live wattage & load monitoring for CPU, Discrete GPU (dGPU), Integrated GPU (iGPU), Screen Backlight, Wi-Fi, SSD/HDD Disk, RAM Bus, and Motherboard.
- 📈 **60-Second Task Manager Style Live Waveform Chart**: Live charging (+W) and discharging (-W) polylines with 5-tier Y-axis dynamic wattage scale.
- 🔌 **AC Adapter Total Supplied Wattage**: Real-time AC input wattage from wall socket vs battery charge rate vs system hardware draw.
- 🟢🔴 **Dynamic Taskbar System Tray Icon**: Real-time wattage numbers rendered directly on Windows Taskbar in Emerald Green (Charging) or Crimson Red (Discharging).
- 🌐 **1-Click Dual-Language**: Instant toggle between Traditional Chinese (繁體中文) and English.
- 🚀 **100% Standalone Portable Executable**: Embedded .NET 8 runtime & native C++ WPF DLLs. Zero dependencies required! Works out-of-the-box on any Windows 10/11 PC.
